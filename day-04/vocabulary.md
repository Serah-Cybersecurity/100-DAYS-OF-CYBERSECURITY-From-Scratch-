# Day 4 Technical Glossary

- **Socket:** An endpoint for communication between two programs running on a network (combination of IP address and port).
- **Encapsulation:** The process of wrapping data with protocol headers as it moves down the OSI stack.
- **Loopback (`127.0.0.1`):** A special IP address used by a host to direct network traffic to itself.
- **Ingress / Egress:** Ingress is incoming traffic into a network; Egress is outgoing traffic leaving a network.
- **Stateful Filtering:** Firewall inspection that tracks the operational state of a connection to make intelligent allow/block decisions.
- **Attack Surface:** The total collection of exposed points through which systems can be accessed or attacked.
- **Network Segmentation:** Architectural division of a network into isolated subnet zones to contain breaches.
