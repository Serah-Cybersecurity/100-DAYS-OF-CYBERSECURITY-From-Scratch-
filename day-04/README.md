# Day 4: Networking Fundamentals & Python Socket Programming

## 🎯 Objectives
- Master foundational networking concepts (OSI/TCP-IP models, encapsulation, packet/frame structures).
- Differentiate hardware routing vs. switching.
- Execute Linux network diagnostics (`ip addr`, `ss`, `ping`, `ip route`).
- Programmatically interact with networking primitives using Python (dictionaries, `socket` module, client-server architecture).
- Understand core defensive security concepts: Attack Surface, Network Segmentation, Firewalls, and the CIA Triad.
- Complete TryHackMe Network Fundamentals / Pre-Security path and Microsoft Learn networking modules.

## 📂 Directory Layout
- **`networking/`**: Core theoretical breakdowns of IP, ports, protocols, and network architecture.
- **`linux/`**: Terminal-based networking commands, routing, and socket state analysis.
- **`python/`**: Custom scripts including service lookups, local network info, IP validation, and TCP client-server sockets.
- **`tryhackme/`**: Structured documentation from guided labs and training rooms.
- **`screenshots/`**: Visual verification of lab environments and script executions.
