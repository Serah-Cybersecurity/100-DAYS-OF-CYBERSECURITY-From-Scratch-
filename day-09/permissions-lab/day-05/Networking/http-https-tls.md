# HTTP, HTTPS, and TLS

## 1. What is HTTP?
Hypertext Transfer Protocol is an application-layer protocol used for client-server web communication transmitted in plain text.

## 2. What is HTTPS?
HTTP securely encapsulated over TLS encryption, protecting web data in transit from eavesdropping and tampering.

## 3. What is TLS?
Transport Layer Security is a cryptographic protocol that provides secure communication channels over a network.

## 4. What is an HTTP Request?
A client-initiated message containing a method (GET, POST), path, headers, and optional body payload.

## 5. What is an HTTP Response?
A server-returned message containing a status code, response headers, and resource data.

## 6. What is a Status Code?
A standardized 3-digit code indicating the outcome of a request (e.g., 200 OK, 404 Not Found, 500 Server Error).

## 7. Why is HTTPS Important?
It ensures confidentiality and data integrity, preventing adversaries from reading or modifying web traffic mid-stream.

## 8. Why Doesn't HTTPS Automatically Make a Website Trustworthy?
Encryption protects the transmission channel, not the intent of the website owner. Malicious actors and phishing sites frequently use valid HTTPS certificates.
