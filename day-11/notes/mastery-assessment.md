# Day 11 - Closed-Notes Mastery Assessment

## Section A - Computer and Networking Fundamentals
1. What is the difference between hardware and software?
   * *My Answer:* Hardware refers to the physical, tangible components of a computer system (such as the CPU, RAM, storage drives, and motherboard). Software refers to the intangible set of instructions, programs, and operating systems that tell the hardware what tasks to perform.

2. What roles do the CPU, RAM, and storage perform?
   * *My Answer:* The CPU (Central Processing Unit) acts as the brain of the computer, executing program instructions and performing calculations. RAM (Random Access Memory) provides volatile, high-speed short-term memory for data and programs currently in active use. Storage (SSD/HDD) provides non-volatile long-term retention for files, operating systems, and applications.

3. What happens at a high level when a computer resolves a domain name?
   * *My Answer:* The computer first checks its local cache and hosts file. If not found, it queries a configured DNS resolver (like an ISP or public DNS). The resolver queries root name servers, Top-Level Domain (TLD) servers, and authoritative name servers step-by-step until it retrieves the corresponding IP address and returns it to the client.

4. What is an IP address?
   * *My Answer:* An IP (Internet Protocol) address is a unique numerical identifier assigned to every device participating in a computer network, enabling logical routing, addressing, and communication across local and wide-area networks (IPv4 or IPv6).

5. What is the difference between TCP and UDP?
   * *My Answer:* TCP (Transmission Control Protocol) is connection-oriented, reliable, and guarantees ordered packet delivery with error checking and a three-way handshake. UDP (User Datagram Protocol) is connectionless, fast, and provides best-effort delivery without error recovery or guarantees, making it suitable for streaming or real-time traffic.

6. Why are ports relevant to network communication?
   * *My Answer:* Ports (ranging from 0 to 65535) act as logical endpoints that allow a single IP address to host multiple concurrent network services and applications. They ensure incoming and outgoing traffic is routed to the correct application process.

7. What is the difference between a client and a server?
   * *My Answer:* A client is a device or application that initiates requests for resources or services (e.g., a web browser). A server is a system or program that listens for incoming requests, processes them, and delivers the requested resources or services back to the client.

8. How do HTTP and HTTPS differ at a high level?
   * *My Answer:* HTTP transmits data in cleartext over port 80, making it vulnerable to interception and tampering. HTTPS encapsulates HTTP traffic within an encrypted TLS/SSL tunnel over port 443, ensuring data confidentiality, integrity, and authentication.

## Section B - Linux and Windows
1. What is the difference between a file and a process?
   * *My Answer:* A file is static data stored persistently on a storage medium. A process is a dynamic, running instance of a program loaded into system memory, possessing its own PID, allocated resources, and execution state.

2. What is the purpose of the Linux root directory?
   * *My Answer:* The root directory (`/`) serves as the top-level starting point of the entire Linux hierarchical file system. All files, directories, and mounted storage devices branch downward from this single root structure.

3. What information is stored under /etc in a typical Linux system?
   * *My Answer:* The `/etc` directory holds system-wide configuration files, startup scripts, and administrative settings (such as `/etc/passwd`, `/etc/shadow`, and network configurations) that control how the operating system and its services behave.

4. What is the purpose of /var/log?
   * *My Answer:* The `/var/log` directory stores system log files generated by the kernel, services, and applications (e.g., `syslog`, `auth.log`). These logs are essential for auditing, security monitoring, and troubleshooting.

5. What is a Linux PID?
   * *My Answer:* A PID (Process ID) is a unique positive integer assigned sequentially by the Linux kernel to identify every active process currently running on the system.

6. What is a PPID?
   * *My Answer:* A PPID (Parent Process ID) represents the PID of the process that spawned or created the current child process.

7. What is the difference between a Linux user and a group?
   * *My Answer:* A user is an individual account used to log in and execute processes with specific permissions. A group is a collection of user accounts designed to simplify administrative access management by sharing common file permissions and privileges.

8. What is the difference between a process and a systemd service?
   * *My Answer:* A process is any running execution instance on the system. A systemd service is a specific type of background daemon managed and supervised by the systemd init system, providing automated startup, monitoring, logging, and restart capabilities.

9. What is the general distinction between Windows user mode and kernel mode?
   * *My Answer:* User mode is a restricted execution environment where standard applications run with limited access to hardware and system memory. Kernel mode is a highly privileged, ring-0 environment where the core operating system and device drivers run with unrestricted access to hardware and system resources.

10. Why should you avoid terminating a process merely because its name looks unfamiliar?
    * *My Answer:* An unfamiliar process name could be a critical system daemon, kernel thread, or background dependency required for system stability. Terminating it blindly can cause system instability, crashes, or data loss.

## Section C - Permissions and scripting
1. What do read, write, and execute permissions mean?
   * *My Answer:* Read (`r`) permits viewing file contents or listing directory contents. Write (`w`) permits modifying, creating, or deleting files within a directory. Execute (`x`) permits running scripts/binaries or traversing through a directory path.

2. How does chmod differ from chown?
   * *My Answer:* `chmod` modifies the access permission bits (modes) of a file or directory (e.g., read, write, execute). `chown` changes the user and/or group ownership of a file or directory.

3. What is the principle of least privilege?
   * *My Answer:* A security best practice stating that users, programs, and processes should be granted only the minimum necessary privileges required to perform their legitimate functions, reducing the potential blast radius of a security breach.

4. What is the difference between a Python list and a dictionary?
   * *My Answer:* A list is an ordered, mutable sequence of items indexed by integers. A dictionary is an collection of key-value pairs optimized for fast lookups using unique keys rather than numerical indexes.

5. Why might a script use a loop when processing log entries?
   * *My Answer:* A loop allows a script to iterate automatically through large volumes of log lines line-by-line, applying parsing, filtering, or analytical logic without manual intervention.

6. What is JSON?
   * *My Answer:* JSON (JavaScript Object Notation) is a lightweight, text-based data interchange format structured around key-value pairs and arrays, making it easy for humans to read and programs to parse.

7. Why should a log parser handle malformed input?
   * *My Answer:* Logs can often be truncated, corrupted, or formatted unexpectedly due to application errors or attacks. Handling malformed input prevents the parser from crashing and ensures continuous execution and data integrity.

8. What is the difference between a script running successfully and the results being correct?
   * *My Answer:* A script running successfully means it executed from start to finish without throwing runtime syntax or fatal errors. Results being correct means the underlying logic, calculations, and output data are logically accurate and verified against expected outcomes.

## Section D - Investigation and reporting
1. What is an observation?
   * *My Answer:* An objective statement of fact or recorded metric gathered directly from logs, system state, or evidence without subjective interpretation.

2. What is a hypothesis?
   * *My Answer:* A tentative, testable explanation for an observed security anomaly or incident that guides further investigation and data gathering.

3. Why does temporal correlation not prove causation?
   * *My Answer:* Two events occurring sequentially or at the same time does not mean one caused the other; they may be coincidental or driven by an independent underlying factor.

4. What is a false positive?
   * *My Answer:* A false positive occurs when a security monitoring tool or analyst incorrectly flags benign, legitimate activity as malicious or anomalous.

5. Why is it important to document the commands you used?
   * *My Answer:* Documenting commands ensures reproducibility, creates a reliable audit trail, and allows other analysts to verify or replicate the investigation steps.

6. What makes a security report reproducible?
   * *My Answer:* Clear documentation of all tools, commands, parameters, environment configurations, and raw data sources that allow another investigator to independently repeat the analysis and achieve identical results.

7. What is the danger of publishing raw system logs?
   * *My Answer:* Raw logs may contain sensitive internal IP addresses, infrastructure paths, API keys, passwords, or Personally Identifiable Information (PII) that could be leveraged by threat actors.
