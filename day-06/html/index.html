1. Introduction to Cybersecurity

Cybersecurity is the practice of protecting systems, networks, devices, and data from digital attacks, unauthorized access, and malicious damage. It bridges technical understanding of computer architecture, network protocols, and software security with disciplined, evidence-based investigation to defend critical infrastructure and user privacy.

2. Five Core Concepts I Have Learned So Far

  • Hardware vs. Software & Memory Volatility: Hardware forms physical components, software executes instructions, and volatile RAM holds running processes that reset upon reboot.
  • Network Architecture & Transport Protocols: IP addresses route Layer 3 packets, ports direct traffic to software services, and TCP guarantees reliable connections via handshakes while UDP prioritizes speed.
  • DNS Resolution Mechanics: Domain Name System translates human-friendly domain hostnames into numeric IP addresses over UDP port 53 without downloading webpage payloads.
  • Web Request Lifecycle & HTTP Grammar: The 8-step journey from entering a URL to browser rendering, including HTTP methods (GET, POST), status codes (200, 404, 500), and request/response headers.
  • Evidence-Based Reporting: Distinguishing empirical observations extracted directly from raw logs from bounded operational conclusions without jumping to unproven assumptions.

3. What I Hope to Learn Next

As I progress through my learning path, I look forward to advancing into client-server interaction testing using Python's http.server, mastering Browser Developer Tools for live network inspection, and transitioning into intercepting proxies (Burp Suite/OWASP ZAP) to analyze web application security risks like Cross-Site Scripting (XSS) and SQL Injection (SQLi).
